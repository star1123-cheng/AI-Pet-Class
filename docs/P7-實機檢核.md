# P7 實機檢核表（教師看板）

先依 `docs/deploy.md` 第 10 節建立並部署看板專案，學生端也要推送新版並重新部署（新增 `reportTask` 與能量重設）。每項勾選後在「備註」寫下觀察。

「Claude 代測」是 2026-10-26 的結果：數字正確性用 `node --test`（30 個模擬序號）驗算；畫面用內建瀏覽器開本機預覽（`google.script.run` 換成模擬資料，寬 1024 與手機 375）。沒有連上真正的 GAS，所以權限、授權、跨專案寫入只能由你實測。
