## ⚠️ 你的待辦（我無法代做）

- [ ] 校內核准：校園帳號讓學生使用 Gemini 與 Canvas，是否需要核准

- [ ] 課程歸屬：排在哪個時段（彈性學習、資訊、綜合活動、導師時間）

### 技術驗證（開發前或第 1 堂前）
- [ ] 用 3 至 5 台學生測試帳號的 iPad，同時在 Canvas 產生網頁，確認速度與穩定度（Gemini 教育版使用上限我查不到明確數字）
- [ ] 試走一次「Canvas 分享到 Classroom」，確認學生帳號能走完；並確認後台該設定已開、學生所在組織單位的 Gemini 為開啟
- [ ] 確認 iPad「引導使用」或 MDM 能鎖定 Safari
- [ ] GAS Web App 能被學生校園帳號從 iPad Safari 存取（部署權限需實測）

### 部署（第 1 堂前）
- [ ] 學生端 GAS 推送並重新部署（P3、P7 新增的 API 還沒上線；舊版會把範例、前測、自報任務當錯誤丟掉）：`docs/deploy.md` 第 1、6 節

| 專注設計 | 每 10 至 12 分鐘換活動；兩人分工；只在課堂玩 |
| 評量 | 遊戲內任務、前後測、作品與提示詞歷程、自評；無個人排名，用班級合作指標 |

## 開發順序與用法

1. 專案根目錄已含 `docs/`、`prompts/` 與 `CLAUDE.md`（`CLAUDE.md` 已在根目錄，不需再複製）
2. 依序把 `P1` 至 `P8` 一個一個交給 Claude Code，上一個通過完成標準再做下一個
3. **P1 是 go／no-go 關卡**：手指塗鴉在 iPad Safari 的辨識率不足就先改資料型態，後面都先不做
4. 規格與實作不一致時，改 `docs/`（單一來源），再改程式
